# Guide to Comparing Domestic Coffee Franchises

**Creator:** Prakash Tamang  
**Project type:** Student mission — franchise comparison webpage  
**Industry:** Coffee franchises in South Korea  
**Comparison metric:** Number of franchised outlets at year-end 2025 (stores)

## Project overview
This responsive, single-page website compares Mega MGC Coffee, Compose Coffee, and Paik's Coffee using one metric and one base year. It includes brand introductions, a comparison table, ascending/descending sort buttons, a four-query search-history explanation, English and Korean summaries, and links for further source verification.

## Tools used
- ChatGPT: page content, HTML, CSS, JavaScript, and comparison structure
- Web search: research and source discovery
- GitHub: version control and hosting repository
- Vercel: intended static-site deployment

## Research sources
- Leaders Fact, 2023–2025 coffee franchise outlet comparison based on KFTC data: https://www.leadersfact.co.kr/news/articleView.html?idxno=23623
- Korea Fair Trade Commission: https://www.ftc.go.kr/eng/
- FTC Franchise Business Transaction portal: https://franchise.ftc.go.kr/
- Yonhap News, 2022 coffee franchise data (context only): https://en.yna.co.kr/view/AEN20250408005300320

## Three details checked or modified for this project
1. The comparison uses the same metric for every brand: franchised outlet count, not corporate revenue or franchisee sales.
2. The table uses a shared base year (year-end 2025) and clearly labels the unit as stores.
3. Sorting is performed only when each row has a numeric comparison value; source notes warn that figures can vary by reporting date and definition.

## Important limitation
The outlet counts are attributed to a secondary industry report and are not claimed to be direct extracts from the official disclosure portal. Verify each brand's 2025 disclosure document on the FTC portal before relying on the figures for investment. Store count alone does not indicate profitability.

## Run locally
Open `index.html` in a modern browser. No build step or external API is required.
